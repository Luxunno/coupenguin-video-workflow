# 高松灯爱音语音包

## 位置与状态

用户已确认把语音包放入上传目录中的对应位置。相对于本 Skill：

```text
assets/voice-packs/高松灯爱音语音包/
```

安装和分发 Skill 时保留这个目录及原有分类。后续使用根据 Skill 的实际安装位置查找，不依赖原电脑的 Downloads 路径。

用户说明其中有高松灯、爱音相关常用语音，以及咕咕嘎嘎等片段。具体文件、格式和条目以实际目录为准；首次使用由 Agent 读取，无需用户再找一遍。此次文档更新未逐个读取或试听音频。

## 自动匹配与使用

1. 递归查看实际目录，先按文件名、角色和分类查找；支持 mp3、wav、m4a、ogg、flac 等实际存在的音频格式。
2. 从已确认脚本提取台词、拟声词、情绪和时长需求。例如“得意地咕咕嘎嘎”同时搜索原词、近似写法和已有情绪标签。
3. 对需要分辨的候选试听，选择适合该镜头的片段。语音已经符合目标声线时直接用，不强制 RVC。
4. 将选中的音频复制到当前制作工程，完成裁切、停顿、音量和时间对齐，保留原语音库供后续使用。
5. 与表演一起放进样片和 GMod 预览。只有不同版本明显改变笑点、剧情或风格时，再给用户少量试听候选。
6. 使用过的文件补充实际台词或别名、情绪标签和用途，保存到简单索引，后续优先复用。

本包没有所需内容时，Agent 继续查其他本地素材、常用语音网站或原音来源。需要原创台词且没有合适音源时，整理录音提示，请用户录音后再处理。

## 简单索引

沿用已有素材索引，或在可写的本地素材库中保存普通 JSON/表格。字段可包括名称、角色、别名、用途、相对路径和来源。标签如“咕咕嘎嘎”“惊讶”“庆祝”在实际查听后填写；不预造文件名、时长或条目数量。

索引和加工副本可以放在项目或共享素材目录，安装目录只读时也能使用。无需哈希或数据库，不修改原音频来满足索引格式。

如果新安装环境确实缺这个目录，先检查是否漏复制 assets，说明缺口并继续其他制作，不把“重新上网找语音包”作为默认要求。
