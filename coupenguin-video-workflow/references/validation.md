# GMod 预览与成片交付

## GMod 用户预览前，集中检查一次样片

场景、动作和分镜搭好后，Agent 先做一次低成本样片验收，再邀请用户进 GMod。样片只需足以判断剧情段落、主要动作和镜头是否正确；用预览画质或录屏即可，不必按最终画质渲染。

集中查看明显穿模、错误动作、镜头遮挡、漏段和明显音画错位，发现问题直接修正。这是一个集中检查节点，不在建模、配音和每次小改动之后反复出样片。

## 用户在 GMod 中看搭建效果

样片检查后，让用户在 GMod 中看。Agent 给出实际的打开或播放方式，必要时提供按镜头重播入口。

请用户关注：
- 角色、道具和场景。
- 动作、表情和互动。
- 机位、构图和镜头切换。
- 整体节奏与创意是否到位。

明确匹配的语音、动作和其他资源合在这个预览中看，不额外逐项批准。用户给出自然语言意见，由 Agent 调整；用户也可主动在 ActMod 选择动作或手动微调，Agent 保存并接回工程。不增加全帧校验。

## 拍摄后做简单检查

打开成片，确认能正常播放、画面和声音都有，听看是否有明显错位、漏台词或错误镜头。用户指出效果问题后继续调整即可。

默认不执行哈希校验、全帧扫描、完整解码流水线或生成技术验收报告。特殊交付规格由用户提出时，再补相应检查。

## 常见问题按需处理

| 现象 | 处理方向 |
|---|---|
| 角色或地图缺贴图 | 查看素材依赖和材料路径 |
| 找不到指定动作 | 查动作插件、载体模型与内部序列名 |
| 人类动作放到企鹅上变形 | 调整骨架映射、比例和动作幅度 |
| 玩偶离手、穿模 | 调整握点、道具轨迹和手臂姿态 |
| 多种动画相互覆盖 | 统一动作、表情和道具约束的更新顺序 |
| 模型碎面或缺部件 | 检查网格导入、法线及数据分块 |
| 换声失真、漏字 | 换参数、处理输入音频或重录相关句子 |
| 结尾出现原声 | 检查是否混回了完整原音 |
| 音画整体错位 | 移动音轨，检查裁切与转换延迟 |
| 实时录制卡顿 | 减轻场景负担或改用逐帧输出 |

这些是遇到问题时的处理参考，不是每次创作都要执行的清单。

## 最后交付

给出成片、工程位置，以及继续修改动作、镜头和声音的入口。素材来源放在项目说明中即可，不必让用户阅读制作日志。
