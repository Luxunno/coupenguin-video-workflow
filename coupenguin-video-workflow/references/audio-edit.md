# 音源、录音、RVC 与音画同步

凑企鹅视频的声音制作有两条常用入口：导入已有音频，或用户通过麦克风录音。两者准备成干净的声音后，都可以送入 RVC 换声，再放回作品中。按题材选择流程，不固定“先拍视频再做配音”。

## 优先使用随包常用语音

用户已确认语音包放入对应目录。本 Skill 优先使用 assets/voice-packs/高松灯爱音语音包/ 中的实际音频，详见 [语音包说明](voice-pack.md)。根据已确认脚本搜索台词和文件名，选择咕咕嘎嘎等合适片段，完成裁切、音量和时间安排。已经是目标声音的片段可以直接使用；需要改变音色时再送入 RVC。

Agent 自己从已确认脚本提取台词、情绪和节奏，搜索音频并选用，负责裁切、停顿、音量与画面入点。明确匹配的声音直接合入预览；不同语气会改变笑点时才提供少量试听候选。实际使用后记录别名、用途和位置，方便下次复用。

本地语音不足时继续找补充来源。确实没有所需台词时整理好录音台词与语气，请用户录制，再由 Agent 处理和换声。

## 路线一：导入音频后换声

适用于现成对白、歌曲、梗音源或视频中的声音。

1. 获取用户文件，或根据已确认脚本寻找对应音源。优先从随包“高松灯爱音语音包”挑选台词或梗音，缺少时再查[常用语音网站](https://apps.125ks.cn/qwyy/gxd2/)等来源。用户给的是视频时，提取所需音频。
2. 截取要用的片段，保留适当的开头和尾音，调整明显过小或过大的音量。
3. 纯对白或干声可以直接换声；带音乐的音源根据效果需要分离人声。
4. 用目标 RVC 声线转换，试听并调整参数。
5. 将转换后声音与伴奏、环境声和音效混合，放入剪辑时间线。

不需要改变的背景音可保留。短梗音源如果直接转换效果已符合创意，就不必为了流程完整而强制分离。

## 路线二：用户麦克风录音后换声

适用于原创台词、旁白、对话、拟声词或自己演唱。

### 准备录音

Agent 根据剧情整理台词、说话角色、语气和大致节奏。用户可直接自由发挥，也可以按台词分句录，毋须精确卡到某一帧。

使用系统录音机、Audacity、剪辑软件或其他已有工具。选择实际使用的麦克风，试听输入，避免麦克风选错或录到扬声器回放。建议戴耳机，在相对安静的位置录音；录入音量避免爆音，句头句尾留一点空白。

如果 Agent 能操作录音工具，可先配置输入、工程和保存位置，再让用户开始说话；工具访问麦克风需要系统权限时，由用户完成授权。没有录音接口时，用户自行录好文件，Agent 接手后续处理。

### 录制方式

- 分句录音：便于重录、多人对白和调整停顿。
- 整段录音：适合自然表演、说唱和连贯情绪。
- 对画面录音：适合已经搭好动作和分镜的片段。
- 先录后拍：适合由语气、节奏和笑点决定表演的小剧场。

可以录多个版本，选择符合角色的语气。用户不必模仿目标角色的音色，重点是台词、情绪、咬字和节奏；RVC 用来转换音色。

### 整理与转换

保留原始录音，挑选合适 take，删去口误和过长空白；按需做轻度降噪、淡入淡出与音量调整。避免过度降噪破坏辅音和气声。对白可导出 WAV 作为中间文件，单声道通常够用。

之后进入与导入音频相同的 RVC 换声环节。需要重录的句子单独替换即可，不必重新录整片。

## RVC 的使用

准备目标声线权重，若该模型提供配套索引则一起加载。根据所用版本选择 GUI 或脚本入口，不假定所有整合包的命令一致。参考 [RVC 项目](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI)。

主要调整项：
- 声线/说话人：选择当前角色。
- 音高偏移：按原声音域与目标效果调整，0 半音可作为起点。
- 音高提取方式：使用当前工具支持的方法，听效果再选。
- 索引混合：在音色相似与清晰自然之间调整。
- 辅音或气声保护、音量包络：工具支持时按需要调整。

先转换当前素材的一小段来听参数，再处理选定内容；这属于声音调节，不是额外的视频样片流程。对白、唱歌、尖叫和拟声词可以使用不同设置，没有一组适用全部场景的固定参数。

RVC 改变音色，表演内容来自输入音频或录音。新台词需要用户录制或另行使用合适的语音工具。

## 音乐、效果与多人对白

人物对白、音乐和音效尽量分别放轨，便于改动。多人对话可分别换声、分别排时间。效果不佳时再使用分离工具，工具与模型按素材选择。

爆炸、脚步、撞击、转场等音效围绕画面事件安排。想增强某个效果就调整该轨音量；不必使用旧作品的固定分贝数。保留尾声时注意不要顺带叠回本来要换掉的原人声。

## 和画面对齐

先定共同的时间线，再摆放声音：
1. 对白对开口和反应，音乐对节拍与舞蹈，音效对动作发生点。
2. RVC 输出有整体延迟时，移动音轨对齐。
3. 句子长度不合适时，调整停顿、动作节奏、剪辑点，或重录；需要时再小幅变速。
4. 口型可跟随最终对白或歌声更新；基础开合即可满足的镜头不必做精细音素对齐。
5. 播放查看和试听有无明显错位，依据用户反馈调整。

既可以让动作适配声音，也可以让声音适配已经喜欢的动作。不要求采样级日志、哈希、逐帧对齐检查或专门验证报告。

## 混音和导出

在整段播放中调整对白清晰度、音乐存在感和音效冲击感，避免明显爆音。按需要加字幕、淡化和转场后导出。

用户可在换声后试听，也可以在观看完成视频时一起提意见。保留录音、换声结果和剪辑工程，方便下次更换台词或声线。

使用 FFmpeg 时，可调用其提取、裁剪、混音和编码能力；使用剪映、DaVinci Resolve 等时，保留对应工程即可。[FFmpeg 滤镜文档](https://ffmpeg.org/ffmpeg-filters.html)
