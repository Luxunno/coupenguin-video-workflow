# 场景、动作与分镜

## 从确认的脚本形成分镜

先与用户讨论并确认大致脚本，再展开分镜。脚本主要讲清人物、事件、表演或笑点、声音与结尾；不用让用户填写技术参数。分镜可以很简单：

| 段落 | 表演 | 镜头 | 声音 |
|---|---|---|---|
| 开场 | 企鹅推门进入房间 | 门口中景 | 脚步与一句台词 |
| 反应 | 看到桌上的东西，转头停住 | 脸部近景 | 停顿或梗音效 |
| 结尾 | 做一个夸张动作 | 拉远或切全景 | 音乐进入 |

这是从零创作示例，段落、题材与时长自由调整。参考改编同样先抓用户想要的内容，再安排凑企鹅表演，不要求逐帧照搬。

## 搭建场景

选择合适地图或自行布景，将角色、道具和灯光放到镜头需要的位置。保存本项目的角色位置、机位和关键设置，方便用户预览与 Agent 修改。

地图名、角色坐标、机位由实际场景决定。室内先处理墙体遮挡，室外关注地面和光照。拍摄时隐藏影响画面的 HUD、武器和光标。

可直接使用游戏地图、搭建简易布景或用其他工具渲染；选择能实现当前效果的方案。

## 默认按描述从 ActMod 匹配动作

确认 ActMod 可用后，Agent 查看实际动作列表、分类或注册信息，将脚本里的动作和情绪对应到候选。例如“得意地扭两下”可以匹配摆动/庆祝类动作，调整片段和循环次数，并加上合适的头部与表情。

明确匹配的动作直接应用，不要求用户知道名称。用户想自行挑选时，再打开 ActMod 选择入口；收到选中项后由 Agent 继续编排。只有动作差异明显影响笑点、剧情或风格时，才集中展示少量试播候选。

动作列表暂时读不到时先检查插件、界面和注册信息；确实只能人工操作时，让用户完成最小的选择操作，不要求用户去找动画文件。

## 应用选定动作

优先使用 Agent 匹配或用户指定的 ActMod 动作；必要时结合已有 sequence、PAC3 配置或其他动画资源。Agent 可查看角色和动作载体的骨骼、表情与序列列表，再将语义动作对应到内部名称。

操作顺序：
1. 按用户描述选定动作，或读取用户在 ActMod 选中的条目，查对应的内部名称。
2. 找动作所在插件、模型或动画文件。
3. 在实际载体中找到可播放的 sequence。
4. 将动作应用到角色，调整速度、循环、朝向和起止时间。
5. 和镜头、道具、声音组合成完整表演。

角色本身没有某个舞蹈序列，不等于动作不能用；动画可能在单独载体中。可让插件负责驱动，或将载体骨骼映射到企鹅。

相关接口：[GetSequenceList](https://wiki.facepunch.com/gmod/Entity:GetSequenceList)、[SetCycle](https://wiki.facepunch.com/gmod/Entity:SetCycle)。PAC3 的动画配置参考 [Animation part](https://wiki.pac3.info/part/animation)。

## 自定义动作与骨架匹配

没有适合的现成动作时，可用 Lua、PAC3、Blender 关键帧或导入动作编排。主要考虑：
- 源、目标角色的初始姿态、朝向和缩放。
- 身体、头、手臂、腿的语义映射。
- 骨长差异，尤其是人的手臂与企鹅短鳍肢。
- 根位移和脚底接触。
- 姿态与表情是否被其他动画覆盖。

先用源动作相对初始姿态的变化驱动目标，再按目标比例调整。必要时使用 IK、关键帧修正或烘焙。不要将手臂拉长当成唯一的匹配方法；也可以改变动作幅度、身体倾斜和道具位置，让表演更适合企鹅。

用户需要具体舞蹈时保留其辨识动作；用户只要求“开心地跳一下”时，Agent 可以自由设计。

没有合适现成动作时，Agent 可组合片段、制作关键帧，或在用户愿意时提供手动调整入口。先把角色、镜头和接近目标的姿态搭好，说明具体需要微调的位置；将用户调整后的结果保存到工程和素材索引中，不让用户从头制作。

骨架或动作的技术缺口先由 Agent 解决。替代后如果明显改变用户想要的表演，再解释差异并让用户决定。

## 道具和角色互动

举物、抱玩偶、拿话筒等动作，可以用道具局部握点辅助控制双手或鳍肢。确定谁主导运动：角色带动道具，或道具轨迹带动双臂，避免冲突。

丢物时在释放点切换为独立运动；坐下、走路、击打和多人互动也以关键接触点组织。接触问题默认由 Agent 调整；用户愿意手动微调时，提供已就位的场景并保存调整结果。

本片没有互动道具时跳过这些设置。

## 表情和说话

使用角色实际支持的 flex 或骨骼控制嘴、眼和头部。基础说话可用声音强弱驱动开口，加上眨眼、点头和停顿；需要精细嘴型时再做更细的发音对应。

多人对白分角色驱动，轮到谁说话再触发其嘴型和表演。夸张梗视频可以故意延迟反应或放大动作，按创意安排。

## 让用户在 GMod 中看

搭好完整场景、动作和镜头后，先集中制作并检查一次样片，修正明显问题，再邀请用户进入 GMod。停在容易开始预览的位置，给出实际可用的播放方式。最好支持整段播放和按镜头重播，便于用户指出修改点。

用户只需表达“抬高一点”“镜头近一点”“这里停半秒”“换个动作”等意见；由 Agent 修改工程。样片检查只放在这次用户预览之前，其他日常调整直接在游戏里查看，不反复导出。
